# Pyramid Principle (Minto) for Consulting Decks

## Core idea

Lead with the answer. Decompose top-down. Group ideas MECE. Defend with evidence at the bottom.

This inverts the natural human tendency to build toward a conclusion. Senior executives need the "so what" in the first minute to allocate cognitive budget for the rest.

## Structure

```
                  Governing Thought
                  (one sentence; the recommendation or main answer)
                          |
        +-----------------+-----------------+
        |                 |                 |
   Pillar 1          Pillar 2          Pillar 3
   (MECE)            (MECE)            (MECE)
        |                 |                 |
   Evidence          Evidence          Evidence
   (data, charts,    (data, charts,    (data, charts,
    quotes, exhibits) quotes, exhibits) quotes, exhibits)
```

- **Governing Thought**: the executive summary in one sentence. The deck's "so what."
- **Pillars**: 3 (Rule of Three) MECE supporting arguments. Mutually Exclusive, Collectively Exhaustive.
- **Evidence**: data, charts, quotes, examples. Each pillar gets its own section.

## Two narrative shapes (use one consistently per deck)

### SCQA (Situation–Complication–Question–Answer)

Best for problem-framing decks (advisory, recommendation).

- **Situation**: factual baseline the audience agrees with.
- **Complication**: change/threat/opportunity that makes the situation unsustainable.
- **Question**: the implicit question the complication raises.
- **Answer**: the governing thought.

### SCR (Situation–Complication–Resolution)

Compressed SCQA. Question is implicit. Resolution = answer + supporting plan.

- **Situation**: 10-20% of executive summary.
- **Complication**: 10-20%.
- **Resolution**: 60-70% — recommended path forward.

## Cognitive load rules

- Working memory holds 3-4 chunks at most. Use the Rule of Three.
- Per slide: one idea. Multiple ideas = split into multiple slides.
- Per section: 3 (max 4) sub-points.
- Per body bullet: ≤ 2 lines.

## MECE check

For every grouping (pillars, options, factors), ask:
- **Mutually Exclusive**: do any two items overlap? If yes, refactor.
- **Collectively Exhaustive**: is anything missing from the universe? If yes, add it (or scope it out explicitly).

Common MECE failures:
- "Customer A, Customer B, Other customers" — "other" is a refuge for unstructured items.
- "Cost, Time, Risk, Other" — same.
- "Short-term and long-term" — what about medium-term?

## Tests for the deck

- **Title test**: read only slide titles top-to-bottom. Do they tell the story?
- **So-what test**: for each slide, what's the conclusion? If the title doesn't state it, fix the title.
- **Pyramid test**: does each pillar's evidence actually support the pillar? Does each pillar actually support the governing thought?

## Anti-patterns

- Burying the lead (governing thought in slide 18 instead of slide 2).
- Topic titles ("Market Overview", "Our Approach") instead of action titles.
- Data dumps without conclusions.
- More than one idea per slide.
- Bullets that aren't grouped (random order vs. logical order).
- Inconsistent narrative shape mid-deck.
